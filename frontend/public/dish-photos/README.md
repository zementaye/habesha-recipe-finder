# Dish photos

Drop real photos here, named exactly after the dish's `id` from
`backend/all_dishes_merged.json`, e.g.:

    doro_wat.jpg
    key_wat.png
    tibs.webp

Any of .jpg/.jpeg/.png/.webp works — the app tries each extension in
turn for a given dish id. A dish with no matching file here just shows
a plain placeholder icon instead of a photo; nothing breaks.
